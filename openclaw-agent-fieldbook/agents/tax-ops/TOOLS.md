# Tax Operations Tools

Private implementations may include:

- transactions ledger
- chart of accounts
- vendor map
- card/bank CSV profiles
- receipt OCR review queue
- tax rule references
- report generator

Public templates should not include:

- real transaction CSVs
- business registration numbers
- taxpayer flags tied to a real entity
- vendor/card identifiers
- receipt images
- accountant contact details
- filing account credentials
