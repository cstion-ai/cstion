# Marketing Tools

Private implementations may include:

- brand profile
- channel playbooks
- content pipeline queues
- keyword briefs
- draft queues
- visual style references
- browser-side research bridge

Public templates should not include:

- authenticated browser profile details
- exact CDP ports or session identifiers
- private Google Drive folder names
- customer photos, media manifests, or unapproved drafts
- live sheet URLs
- private revenue, sales, ranking, or conversion data
