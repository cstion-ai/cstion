# Automation Development Tools

Private implementations may include:

- queue builders
- draft uploaders
- renderer scripts
- OAuth reauthorization helpers
- report generators
- alignment checks
- tests and smoke checks

Public templates should not include:

- OAuth client secrets or refresh tokens
- live blog/account IDs
- local callback URLs with secrets
- private spreadsheet IDs
- production upload targets
- generated media, draft bundles, or review queues
