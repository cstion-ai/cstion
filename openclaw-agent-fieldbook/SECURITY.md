# Security Policy

This repository is intended to contain public-safe templates only.

Do not commit:

- tokens, API keys, OAuth refresh tokens, app passwords, or session cookies
- local device identifiers, authenticated browser profiles, Telegram allow lists, or private account bindings
- customer, staff, employee, payroll, tax, legal, medical, or personal contact data
- raw memory journals, chat transcripts, media files, logs, exports, databases, or generated drafts
- exact private machine paths such as `<HOME>/private-workspace/...`

When adapting the templates, keep private facts in local files ignored by git, and keep public prompts written in placeholder form.
