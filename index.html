Kakao OAuth

카카오톡 접속 시 로그인 방법

카카오톡 채널 또는 웹뷰에서 예약을 시작하면 카카오 OAuth 2.0 인가 코드 흐름으로 사용자를 확인하고, CRM 고객 프로필과 연결합니다.

  1. REST API 키 설정Kakao Developers에서 앱을 만들고 Redirect URI를 등록합니다.
  2. 인가 URL 생성buildKakaoLoginUrl()로 client_id, redirect_uri, state를 포함한 로그인 URL을 만듭니다.
  3. 인가 코드 수신카카오가 /auth/kakao/callback?code=...&state=...로 사용자를 돌려보냅니다.
  4. 토큰 교환 및 CRM 연결exchangeKakaoAuthorizationCode()로 토큰을 받고 고객 프로필을 생성/갱신합니다.
