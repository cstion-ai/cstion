# Support

Support is provided on a best-effort basis; response times are not guaranteed.

- Ask open-ended usage questions in [GitHub Discussions](https://github.com/cstion-ai/cstion/discussions/categories/q-a).
- Share an evaluation, prototype, or deployment through the [Show and tell form](https://github.com/cstion-ai/cstion/discussions/categories/show-and-tell).
- Report reproducible bugs with the [bug report form](https://github.com/cstion-ai/cstion/issues/new?template=bug_report.yml).
- Propose reusable improvements with the [feature request form](https://github.com/cstion-ai/cstion/issues/new?template=feature_request.yml).
- Report suspected vulnerabilities privately by following the [Security Policy](SECURITY.md). Do not open a public issue.

Use synthetic or redacted data in every report. Never post credentials, access tokens, customer data, or unredacted logs.

Issues track actionable defects and scoped improvements. Discussions are the right place for evaluation notes, design questions, and early ideas.
