# Adoption evidence

This page records permissioned, third-party use of the project without turning repository activity into a marketing claim.

## Current evidence

No verified third-party adopters are listed as of 2026-07-27.

That is an intentional empty state. Stars, forks, clones, page views, template uses, maintainer-created examples, and automated CI traffic do not prove that another person evaluated or deployed the project.

## Evidence stages

| Stage | Minimum evidence |
| --- | --- |
| Local evaluation | A third party reports running the project and names the evaluated path or result. |
| Prototype | A third party describes a proof of concept and the components or adapters they changed. |
| Non-production deployment | A third party reports a deployed test environment and its validation scope. |
| Production deployment | A third party confirms live use, describes the relevant boundaries, and explicitly permits public listing. |

Reports may remain anonymous. A public link is helpful but not required; the originating GitHub account and permissioned discussion are sufficient for a stage below production.

## Report an evaluation

Use the [Show and tell evaluation form](https://github.com/cstion-ai/cstion/discussions/categories/show-and-tell). Include only synthetic or redacted material.

The maintainers will:

1. check that the report came from someone outside the maintainer account;
2. confirm the reported stage and evidence;
3. request explicit permission before adding a summary here;
4. link the original public report when permission allows; and
5. remove or anonymize a listing when its reporter asks.

## What this page will not claim

- A star or fork is not an adopter.
- A clone or page view is not an evaluation.
- Passing project CI is not an external deployment.
- A private production claim without permission is not a public case study.
- A maintainer-created demo is product evidence, not community evidence.
