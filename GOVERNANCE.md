# Governance

## Maintainer model

This project has one primary maintainer: [@cstion-ai](https://github.com/cstion-ai).

The primary maintainer has final authority over pull requests, releases, security coordination, repository administration, and governance.

## Decisions

Routine changes are decided in pull request review. Changes with architectural, migration, security, or privacy effects begin with an issue that states the problem, alternatives considered, and expected impact.

The decision and its rationale are recorded in the associated issue or pull request. Vulnerability details and private user information remain in private security channels.

## Maintainer access

A contributor may be considered for maintainer access based on:

- sustained, constructive contributions;
- sound review judgment;
- respect for privacy and security boundaries;
- reliable follow-through on issue triage and accepted changes.

The primary maintainer decides whether to grant or revoke access and limits it to the responsibilities assigned.

## Changes to governance

Governance changes are proposed in a public pull request. The pull request remains open for at least 14 days before a decision, and the primary maintainer records the final decision and rationale there.
